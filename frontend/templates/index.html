О проекте

Этот демонстрационный сайт создан для презентации готовых компонентов, которые можно использовать при разработке веб-приложений. Все компоненты разработаны с использованием современных технологий:

  • Backend: FastAPI - быстрый и современный Python фреймворк
  • Frontend: HTML5, CSS3, JavaScript (ES6+)
